# Create Documentation

Quando solicitado:

Create Docs <Feature>

Gerar automaticamente toda a documentação da funcionalidade.

## Gerar

- README da Feature
- Documentação da API (Swagger/OpenAPI)
- Fluxo da funcionalidade
- Estrutura de diretórios
- Dependências utilizadas
- Regras de negócio
- Exemplos de requisições
- Exemplos de respostas
- Códigos HTTP utilizados
- Casos de erro
- Variáveis de ambiente (quando necessário)

## Sempre verificar

- Clareza
- Organização
- Atualização da documentação
- Consistência com a implementação

Toda funcionalidade deve possuir documentação.
