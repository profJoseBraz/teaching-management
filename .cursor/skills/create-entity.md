# Create Entity

Quando solicitado:

Create Entity <Nome>

Criar uma entidade seguindo os princípios de Domain-Driven Design.

## Gerar

- Entity
- Value Objects (quando necessário)
- Construtores
- Métodos de domínio
- Validações internas
- Interfaces
- Testes Unitários

## Sempre verificar

- Encapsulamento
- Imutabilidade quando possível
- Responsabilidade única
- Regras de negócio pertencem à entidade

Nunca transformar uma Entity em um simples objeto de dados.
