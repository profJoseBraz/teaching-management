# Create Repository

Quando solicitado:

Create Repository <Nome>

Criar toda a estrutura do Repository.

## Gerar

- Interface do Repository
- Implementação
- Datasource
- Mapeamentos
- DTOs (quando necessário)
- Testes Unitários

## Sempre verificar

- Repository Pattern
- Inversão de Dependência
- Baixo acoplamento
- Reutilização
- Tratamento de erros

Repositories nunca devem conter regra de negócio.

Repositories apenas persistem e recuperam dados.
